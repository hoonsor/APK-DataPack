## 1. 文件概覽

### 產品願景
拍下或說出任何值得留的資料，賈維斯自動分類、抽取並歸檔，之後用一句話查得到，而且每個答案都能回到原始照片或頁面核對。

### 使用者
只有倬一人，手機是 OPPO Reno 14F（ColorOS），電腦 A、B 各一台。

### 成功指標（完成定義）

| 指標 | 目標 | 怎麼驗 |
| --- | --- | --- |
| 端到端 | 真實名片與說明書走完拍照、清晰化、抽取、語音查詢、回原圖 | 實機 |
| 通用性 | 新增資料包只改設定，不發版 | 第一版期間新增第 6 種資料包測試 |
| 名片 OCR | 姓名、公司、電話正確率 ≥ 95% | 真實名片 20 張基準 |
| 健檢 OCR | 數值正確率 ≥ 98%，未核對的數值不進統計 | 真實報告基準 |
| 查詢命中 | 固定 30 題，答案與來源都對 ≥ 90% | 基準題庫 |
| 來源可追溯 | 每個事實型答案 100% 帶來源，查無資料時直說 | 基準題庫 |
| 回應時間 | 表格查詢 ≤ 8 秒、文件查詢 ≤ 12 秒（4G） | 實機 |
| 擷取時間 | 單張名片 ≤ 15 秒入庫；100 頁文件背景 ≤ 10 分鐘 | 實機 |
| 成本 | 不開新 Supabase 專案，不增加付費服務 | 帳單與額度頁 |

## 2. 商業與競爭分析

自用工具，不做商業化。對標的不是單一 App：

| 同類 | 強項 | 本產品的差異 |
| --- | --- | --- |
| Adobe Scan、Microsoft Lens、Google 文件掃描 | 裁切與清晰化 | 直接用 ML Kit 同等能力，重點放在掃描後的抽取與查詢 |
| CamCard 等名片 App | 名片辨識 | 不只名片；用說的跨類型查詢 |
| 筆記 AI（NotebookLM 類） | 文件問答 | 圖片留手機，接倬的語音總控，能列全與統計 |

護城河是接進倬自己的語音入口與資料規則，不是 OCR 本身。

## 3. 使用者旅程

**旅程 A：拍名片**
1. 開資料包 APP 按「掃描」，或從語音總控說「掃名片」。
2. 掃描器自動抓邊、清晰化，可連拍多張，不必選類型。
3. 圖片存到 `Pictures/賈維斯資料包/<資料包>/`，照片 APP 看得到。
4. 手機本機 OCR，通過公務防呆後才送文字到 AI 分類與抽取。
5. 高信心直接入庫並提示結果；低信心進「待確認」。
6. 重複時略過或列出差異請倬決定。

**旅程 B：既有照片送件**  
在照片 APP 單張或多選按「送到資料包」，後續同旅程 A 第 4 步起。

**旅程 C：語音查詢**
1. 對語音總控說「有沒有文具相關的廠商」。
2. 語音總控呼叫 `pack_query`，資料包判斷查哪些資料包：資料表走欄位條件，文件走分段檢索。
3. 語音總控唸重點與來源（「來源：陳小姐的名片」）；資料包同時跳一則通知。
4. 倬點通知或說「看原圖」，資料包打開原圖並高亮答案所在的文字區塊。

**旅程 D：說明書 PDF**  
把 PDF 分享給資料包，有文字層就直接取文字，掃描 PDF 才逐頁 OCR；回答一樣附頁碼。

**旅程 E：記住**  
說「記住保單 3 月 15 日到期」，存成事實。之後改口時保留舊值紀錄，查詢回最新值。

### 資料包設定長相

```json
{
  "key": "business_card",
  "name": "名片",
  "shape": "table",
  "classify": {
    "hint": "印有人名、公司、職稱與聯絡方式的小卡片",
    "examples": ["經理 02-1234-5678 xx有限公司"]
  },
  "fields": [
    { "key": "name", "label": "姓名", "type": "text", "required": true, "searchable": true },
    { "key": "company", "label": "公司", "type": "text", "searchable": true },
    { "key": "phone", "label": "電話", "type": "phone", "repeat": true },
    { "key": "tags", "label": "業務標籤", "type": "tags", "searchable": true,
      "extract": "推論這家公司賣什麼或做什麼，例如文具、影印機" }
  ],
  "dedupe": [["name", "phone"], ["name", "company"]],
  "review": { "mode": "low_confidence", "threshold": 0.8, "must_check": ["name", "phone"] },
  "speech": { "row": "{company}的{name}，{title}，電話{phone}", "limit": 5 },
  "actions": ["call", "contact"]
}
```

規則：
- `shape` 只有 `fact`、`table`、`document`、`table+document`。
- 欄位型別先支援 `text`、`number`、`date`、`phone`、`email`、`tags`、`money`，再加 `rows`（健檢這種一份多列）。
- 計算欄位用 `computed` 指定內建規則，例如 `warranty_end`。
- 設定有版本；改欄位不動舊資料，可選「用新設定重抽」。
- 新形式才需要改程式；新資料包不用。

## 5. 非功能性需求

**資料與隱私**
- 圖片只留手機，雲端只存文字與 OCR 區塊座標。
- 送 AI 的只有文字，不送截圖或原圖。
- 大陸廠牌雲端：**本專案的個人非公務資料可送 MiniMax 國際版**（倬 2026-10-31 決定，見 D3）。其他大陸廠牌雲端服務與中國版不用。
- 人事資料與公文不進系統；誤拍由 F03 攔下。放行紀錄留在本機 Log。
- 金鑰：Android 用 Keystore AES-GCM，由倬在設定頁填入；電腦用 dotenvx；不寫進 repo。

**資料庫**
- 放 `Raphael_Evaluation`，表名 `jv_` 前綴，每張表 RLS，只限本人 `auth.uid()`。
- migration 前先備份。
- 暫定表：`jv_packs`、`jv_pack_versions`、`jv_items`、`jv_item_versions`、`jv_sources`、`jv_chunks`。
- 中文檢索用 `ILIKE`＋命中分數；統計與篩選直接查欄位，不交給 AI 算。

**可靠性**
- 按了掃描就一定有結果：排隊狀態看得到，失敗可重試。
- 刪除先做並給 10 秒復原。
- Supabase 是真實來源；手機保留本機快取，表格類查詢沒網路時仍可查。
- 每筆資料都記錄來源檔案的雜湊，圖片被移動後仍可依雜湊重新連結。

**相容**
- minSdk 30、targetSdk 35；需要 Google Play 服務（Reno 14F 要實測）。
- 語音動作遵守 `AGENT_PROTOCOL.md` 相容規則；協定 api 1 不動。

## 6. 超出範圍

- 不存圖片到雲端；不開新 Supabase 專案。
- 不收公文、人事資料。
- 不做多人共用、不上架。
- 不做第一版的到期提醒、Claude／拉斐爾讀取、健康趨勢圖（見 P1）。
- 不把 OCR 放進 `APK-Photo`，也不打破它「照片不經網路」的承諾。
- 語音總控不改程式，只更新使用說明書。

## 7. 風險與相依

| 風險 | 影響 | 緩解 |
| --- | --- | --- |
| ML Kit 繁中準確度不足（直式名片、小字） | 名片與健檢不可信 | 先用真實樣本量測，不足時改本機 PP-OCR；不改送雲端圖片 |
| 健檢表格欄位對錯列 | 數值張冠李戴，後果最重 | 依座標重建表格列；F18 全部人工核對；未核對不進統計 |
| Reno 14F 的 Play 服務或文件掃描模組不可用 | 掃描失敗 | 健康檢查頁偵測，退回系統相機＋本機裁切 |
| 語音總控 AI 改寫時漏掉來源 | 違反 P7 | 來源通知由資料包自己發，不靠語音總控 |
| 關鍵字召回不足（口語同義詞） | 查不到 | 入庫時抽業務標籤，查詢時擴展關鍵字；不足再做 F29 |
| 長文件吃 MiniMax 額度 | 抽取變慢 | 全文只存不送；重點摘要分批，顯示進度 |
| 手機遺失或換機 | 圖片消失，文字還在 | 備份 zip 可選含圖片；原圖不在時明確顯示 |
| Supabase 免費版無可用備份 | 資料遺失 | 手機備份＋每晚本機匯出，併入 62 號驗證 |
| 名片與健檢是個資且在公有雲 | 外洩風險 | RLS、最小欄位、遮罩身分證、Log 遮罩 |

相依：
- `D:\dev\APK-Photo`：開 feature branch，動工前確認沒有 session 在改。
- `D:\dev\APK-VoiceHub`：只改 `docs/manual/MANUAL.md`，動之前先問 `voice-filler` session。
- 共用簽章：倬要把 `hoonsor/APK-DataPack` 加進 `setup-hoonsor-signing.ps1` 清單再執行一次。
